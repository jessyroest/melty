# CLAIMS

Every claim that melty makes in its UI, metadata, README or how-it-works page, with the code or test that backs it up. A claim without proof is reworded or removed. Last checked: 2026-10-09 (after phase 2 and the finishing round).

- **How to keep this file true:**
  - When you add or change a claim anywhere, add it here with its proof.
  - Run `pnpm check` plus the browser tests (`pnpm e2e`, `pnpm e2e:features`, `pnpm e2e:xss`, `pnpm e2e:resilience`, `pnpm e2e:phase2`).
- **Not claimed:**
  - an independent audit (we say "not independently audited (yet)": `HowItWorks.tsx`, `README.md`)
  - anonymity
  - forward secrecy for the room as a whole: one room key for the whole room, no re-keying (said in `HowItWorks.tsx` "links and words", `README.md` threat model)
  - post-quantum *authentication* (no post-quantum signatures; the link's psk and the safety words do the authenticating; listed under "not yet" in `HowItWorks.tsx`)
  - hiding message timing (listed under "not yet")
