# CLAIMS

Every claim that melty makes in its UI, metadata, README or how-it-works page, with the code or test that backs it up. A claim without proof is reworded or removed. Last checked: 2026-10-09.

- **How to keep this file true:**
  - When you add or change a claim anywhere, add it here with its proof.
  - Run `pnpm check` plus the browser tests (`pnpm e2e`, `pnpm e2e:features`, `pnpm e2e:xss`, `pnpm e2e:resilience`).
  - Never claim "post-quantum" until phase 2 ships with passing tests.
- **Not claimed:**
  - an independent audit (we say "not independently audited (yet)": `HowItWorks.tsx:158,212`, `README.md`)
  - anonymity
  - post-quantum security
  - forward secrecy
  - replay protection or padding (listed as "not yet": `HowItWorks.tsx`, `README.md` threat model)
